# Sign-in artwork sources

Retrieved October 10, 2026. Artwork is used only for the corresponding branded sign-in controls; provider authentication is still a prototype.

- Google guidelines: https://developers.google.com/identity/branding-guidelines
- Google original SVG bundle: https://developers.google.com/static/identity/images/signin-assets.zip (Android + Web, Light, Square). The logo SVG retains the supplied vector paths and gradients, with its viewport isolated from the button frame and text.
- Google Sans Medium: https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap&text=Sign%20in%20with%20Google
- Apple guidelines: https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple/
- Apple button artwork, unmodified: https://appleid.cdn-apple.com/appleid/button?width=200&height=44&color=black&border=false&border_radius=4&scale=3&type=sign-in&locale=en_US

Logos remain the property of their respective owners. Do not recolor or substitute them. Both controls are 44px high, with a separate prototype note and accessible button labels.
